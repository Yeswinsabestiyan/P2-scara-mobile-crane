─────────────────────────────────────────────────────────────
TERMINAL 2 – Keyboard Teleop (Required for Robot Control)
─────────────────────────────────────────────────────────────
source ~/ros2_ws/install/setup.bash
ros2 run scara_arm_description scara_teleop.py

Keys:
  W / S : Drive forward / back
  A / D : Turn left / right
  I / K : Crane column lift up / down
  J / L : Arm shoulder (joint1)
  U / O : Arm elbow (joint2)
  T / G : Slider (joint3) down / up (reaches ground!)
  R / F : Wrist rotate
  SPACE : Gripper toggle (auto-attaches cargo when aligned)
  N     : Respawn cargo
  H     : Return to home pose
  1/2/3 : Speed mode (SLOW / NORMAL / FAST)
  Q     : Quit
